# 공부 기록장 (PWA)

초등학생 공부·독서 기록 앱. 안드로이드 Chrome에서 "홈 화면에 추가"하면 앱처럼 쓰고, 데이터는 **폰 안에만** 저장돼요(서버·로그인 없음).

## 기능
- **책 등록**: 책 뒤표지 ISBN 바코드 스캔 → 제목/저자/출판사/쪽수/표지 자동 입력 (한글책: 알라딘, 그 외: Google Books → Open Library). 못 찾으면 직접 입력.
- **도서관 모드**: 바코드를 찍으면 🔴 이미 읽음 / 🟡 읽는 중 / 🔵 읽고 싶음 / 🟢 새 책을 크게 표시. 연속 스캔 가능.
- **학습 기록**: 한글책, 영어책, 영어책 오디오, 영어 영상, 수학, 기타 학과공부, 메모. 시간(직접 입력/타이머), 읽은 쪽수. 쪽수가 책 전체에 닿으면 완독 확인.
- **단계 관리**: 한글책/영어책 단계명을 설정에서 자유롭게 편집. 책마다 단계와 AR/Lexile 메모.
- **통계**: 주간·월간·연간 항목별 시간/쪽수/완독, 일별·월별 막대 그래프, 항목 비율 도넛, 공부한 날 달력, 연속 학습일, 월별 쪽수·완독 추이, 단계별 완독.
- **엑셀(.xlsx) 내보내기**(학습기록·책목록·월별 통계·항목별 통계 4개 시트), CSV, JSON 전체 백업/복원. 일주일 지나면 백업 알림.

## 폰에 설치하기 (처음 한 번)
카메라와 설치 기능은 **https 주소**에서만 동작해요. 이 폴더(`study-app`)를 무료 호스팅에 올리고 그 주소를 폰 Chrome에서 열면 됩니다.

### 방법 A: GitHub Pages
1. github.com 가입 → 새 저장소(Repository) 만들기 (무료 Pages는 Public 저장소 필요. 이 폴더에는 개인 정보가 없고 기록은 폰에만 있어요. 저장소 이름은 추측하기 어려운 것으로.)
2. 이 폴더의 파일 전체(폴더 `js`, `icons` 포함)를 저장소 맨 위에 업로드.
3. 저장소 Settings → Pages → Branch를 `main` / `(root)`로 두고 Save.
4. 몇 분 뒤 나오는 `https://아이디.github.io/저장소이름/` 주소를 폰 Chrome에서 열기.

### 방법 B: 드래그 앤 드롭 호스팅 (예: Netlify Drop)
폴더를 끌어다 놓으면 https 주소를 주는 서비스를 써도 돼요. 화면과 절차는 서비스에서 확인하세요.

### 폰 Chrome에서
주소 열기 → 오른쪽 위 ⋮ 메뉴 → **앱 설치** 또는 **홈 화면에 추가**. 처음 바코드 스캔 때 카메라 권한을 **허용**하세요. 한 번 열면 이후에는 인터넷 없이도 열려요(책 정보 조회·표지 이미지는 인터넷 필요).

> 앱 파일을 고쳐서 다시 올렸다면 `sw.js`의 `VERSION` 숫자를 올려야 폰이 새 파일을 받아요.

## 첫 설정 (설정 탭)
- **알라딘 TTBKey**: 한글책 정보를 정확히 받으려면 알라딘 OpenAPI에서 키를 받아 입력 (https://www.aladin.co.kr/ttb/apiguide.aspx). 키가 없어도 Google Books/Open Library로 시도해요.
- **단계 목록**: 한글책/영어책 단계를 원하는 대로 수정.
- **목표**: 주간 공부 시간, 월간 완독 권수.

## 알라딘이 조회되지 않을 때 (프록시)
알라딘 서버는 브라우저의 직접 호출을 막을 수 있어요(CORS). 앱은 직접 호출 → JSONP 순서로 시도해요. 둘 다 안 되면 `proxy/worker.js`를 Cloudflare Workers(무료)에 올리고, 설정의 **프록시 주소**에 `https://내워커.workers.dev/?url=` 을 넣으세요. 이 워커는 알라딘 주소만 중계해요.

## 백업 (중요)
브라우저 데이터를 지우거나 앱을 삭제하면 기록도 사라질 수 있어요. 설정 → **전체 백업 파일(JSON) 저장**을 주기적으로 하고, 파일은 구글 드라이브 등에 옮겨 두세요. 폰을 바꾸면 **백업 파일 불러오기**로 복원. (백업 파일에는 입력한 알라딘 키도 들어 있으니 남에게 공유하지 마세요.)

## 파일 구성
- `index.html`, `style.css`, `manifest.webmanifest`, `sw.js`, `icons/`
- `js/util.js` 날짜·ISBN / `db.js` 저장소 / `books.js` 책 조회 / `scanner.js` 바코드 / `xlsx.js` 엑셀 파일 생성 / `charts.js` 그래프 / `core.js` 공통 / `stats.js` 통계·내보내기 / `views.js` 화면
- 외부 라이브러리 없이 동작해요(그래프·엑셀 모두 직접 구현).

## 아직 실제 폰으로 확인하지 못한 것
개발 환경에는 카메라와 인터넷 접속이 없어서, 아래는 코드만 작성했고 **실제 폰에서 확인이 필요**해요.
- 카메라 바코드 스캔 (Chrome의 BarcodeDetector 사용. 안드로이드 Chrome은 보통 지원)
- 알라딘/Google Books/Open Library 실제 조회와 응답 항목(특히 알라딘의 쪽수 필드)
- 홈 화면 설치와 오프라인 동작
화면 표시, 기록 저장, 통계, 도서관 모드 판정, 엑셀/CSV/JSON 내보내기는 폰 크기 화면에서 시험해 확인했어요.
